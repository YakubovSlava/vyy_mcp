Общая директория с навыками

Навыки, установленные здесь, загружаются MCP-сервером и становятся доступны всем пользователям этого сервера.

Используется notebooks/connect_to_mcp.ipynb — см. вкладку «Пользователи».

Если заполнено и в общей директории уже настроен git-репозиторий — после каждого изменения (навык, группа, файл) выполняется git add/commit/push. Пароль здесь никогда не показывается — пустое поле оставляет сохранённый без изменений. Файлы в корне репозитория (всё кроме tools/) загружаются и правятся на вкладке «Файлы».

Этот текст MCP-сервер отдаёт каждому подключившемуся агенту как системную инструкцию (поле instructions при инициализации) — применяется ко всем пользователям сразу, без их участия и без перезапуска сервера (подключение, случившееся прямо в момент сохранения, может ещё увидеть старый текст — со следующего за ним всё будет актуально).

Добавить навык

Загрузите .zip, содержащий либо один .py-файл с одной функцией (code-навык — manifest.json не нужен, функция сама себе манифест), либо SKILL.md (с сопутствующими файлами) для навыка в формате документации. Оба формата описаны на вкладке «Документация».

Имя/описание/группа нужны только для навыков в формате SKILL.md — для .py-навыков они берутся из самой функции и модуля (__group__ = "...") и игнорируются здесь. Группы создаются на вкладке «Группы».

Переименовать навык

Имя — это и папка навыка, и имя MCP-инструмента. У code-навыка переименовывается ещё и сама функция в файле, иначе сервер её не найдёт.

Только [a-z0-9_-], начинается с буквы или цифры, 2–64 символа.
